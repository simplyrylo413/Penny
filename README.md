# Penny

Penny is an AI phone assistant product concept by Incyte Works.

This repo contains the static landing page mockup for Penny, including the embedded Penny logo, responsive layout, animated sample phone-call interaction, restaurant use cases, and call-to-action sections.

## Files

- `index.html` - self-contained static landing page.

## Preview

Open `index.html` in a browser, or deploy it with GitHub Pages, Netlify, Vercel, or any static host.
